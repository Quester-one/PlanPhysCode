## 🔥 Release

We are excited to announce that we have released the resources used in the **pre-training stage** of PlanPhys.

The released resources include:

- ✅ Pre-training datasets (including all checkpoints)
- ✅ Pre-trained models

You can access them through Hugging Face:

- 🤗 **Pre-trained Models**:  
  https://huggingface.co/MultimodalAgent/TianyiMen_PlanPhys_Models

- 🤗 **Pre-training Datasets**:  
  https://huggingface.co/datasets/MultimodalAgent/TianyiMen_PlanPhys_Datasets

We hope these resources can facilitate further research and development in long-horizon multi-turn planning and agentic opd.
